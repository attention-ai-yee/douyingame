# 御兽山海（暂定名）

抖音小游戏 · 竖屏 · 山海经题材 · 放置养成 + 进山十连 · 纯广告变现。

> 注意：在抖音开放平台注册时选 **小游戏**，不是小程序。两者是不同的应用类型，游戏类目、广告变现和审核规则都按小游戏走。

- 设计文档：[docs/游戏设计文档.md](docs/游戏设计文档.md)
- 运营文档：[docs/运营文档.md](docs/运营文档.md)

## 目录结构

```
client/                         Cocos Creator 3.8 工程（用 Cocos Creator 打开这个目录）
  assets/resources/config/      配置表（JSON）：游戏和数值模拟器共用这一份
  assets/scripts/
    core/                       纯游戏逻辑：不依赖 Cocos、不依赖抖音接口，可在 Node 里单测
      systems/                  抽兽、升星、阵位、关卡与镇妖塔、挂机离线、签到
      reveal/RevealSession.ts   现身拍符的判定（按毫秒、按触摸时间戳）
      GameCore.ts               逻辑门面：界面只通过它读写游戏状态
    platform/                   平台层：抖音 tt 接口实现、浏览器调试实现、广告服务、埋点
    app/App.ts                  组装 core + platform，负责存档和前后台切换
    view/Boot.ts                Cocos 启动组件（加载配置表、驱动 App、调试面板）
tests/                          单元测试（vitest）
tools/sim/                      数值模拟器（Python 标准库）
docs/                           设计文档、运营文档
```

### 分层规则

1. `core/` 里**不能** `import 'cc'`，也不能用 `tt`。这样逻辑可以在 Node 里测试，以后换引擎或上微信小游戏只需重写 `view/` 和 `platform/`。
2. 数值**只改配置表**，不要写死在代码里。
3. 改了 `core/formulas.ts` 的公式，要同步改 `tools/sim/sim.py` 的 `Model`。`tests/formulas.test.ts` 会拿两边算出的数比对，不一致时测试失败。
4. 界面脚本放 `view/`，通过 `App.core`、`App.ads`、`App.analytics` 访问逻辑和平台；core 发出的事件（`App.core.events.on(...)`）用来刷新界面。

|---|---|---|
| Cocos Creator | 3.8.6（其他 3.8.x 打开时按提示升级工程即可） | 编辑场景、预览、构建抖音小游戏 |
| 抖音开发者工具 | 最新版 | 预览、真机调试、上传 |

## 常用命令（在仓库根目录）

```bash
npm install          # 第一次
npm test             # 单元测试（含配置表校验、公式与模拟器一致性检查）
npm run typecheck    # 类型检查（core / platform / app / tests）
npm run sim          # 数值模拟：python3 tools/sim/sim.py，可加 --days 180 --seeds 20 等参数
```

改完配置表先跑一次 `npm test`：配置校验会检查兽池每档非空、概率之和为 100%、完美区不低于 70ms 等规则。

## 在 Cocos Creator 里打开

1. 打开 Cocos Dashboard → 项目 → **导入**，选择仓库里的 `client/` 目录。第一次打开会生成 `library/`、`temp/`、`settings/` 和各文件的 `.meta`。`.meta` 和 `settings/` 要提交，前两个已加进 `.gitignore`。
2. 新建场景 `Main`（层级管理器里会自带 Canvas），在 **Canvas 节点**上添加组件 `Boot`。
   - `showDebug` 勾选：左上角显示调试面板（关卡、塔层、战力、金币等）。
   - `autoPlay` 勾选：每秒自动抽兽、升星、升级、推图、爬塔，用来确认逻辑在跑。
3. 菜单 项目 → 项目设置 → 把 `Main` 设为启动场景，点预览。浏览器里用的是模拟广告：URL 后面加 `?ad=skipped`、`?ad=nofill` 可以测试失败分支。

## 构建抖音小游戏

1. 在抖音开放平台创建**小游戏**，拿到 AppID。
2. Cocos Creator → 项目 → 构建发布 → 发布平台选 **抖音小游戏**，填 AppID，设备方向选竖屏，构建。
3. 用抖音开发者工具打开构建输出目录（`client/build/` 下对应抖音的文件夹），预览、真机调试、上传。
4. 首包大小限制、分包规则以抖音开放平台当时的文档为准。首包只放第 1 章资源，后续章节放分包。

## 提审前检查

- [ ] `ads.json` 填好激励视频、插屏的广告位 ID（没填时抖音里会按模拟广告处理，只能用于开发期）
- [ ] `app/App.ts` 的 `RELEASE` 改成对应版本（`mvp0` / `mvp1` …），决定哪些广告位开放
- [ ] `Boot` 组件的 `showDebug`、`autoPlay` 取消勾选
- [ ] 进山界面有「概率说明」入口（游戏设计文档 4.3）
- [ ] 设置页能看到用户协议、隐私政策
- [ ] 软著名称、游戏名称、主体信息逐字一致（运营文档 2.1）
