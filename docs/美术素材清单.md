# 《御兽山海》美术素材清单（交给 ChatGPT 出图用）

> 用法：按下面的步骤让 ChatGPT 出图 → 把原图上传到 GitHub 仓库的 `art/inbox/` 文件夹 → 告诉我，我来裁剪、去背景、缩放并接进游戏。
> 你**不需要**自己裁图、改尺寸，只要**按本清单的中文名命名**即可。

---

## 一、出图步骤

1. 在 ChatGPT 里新开一个对话，**专门用来出这个游戏的图**（同一个对话里画风更容易保持一致）。
2. 第一条消息：先发「二、统一风格」整段，再接上第一只异兽的描述（建议先画**九尾狐**）。
3. 满意之后，后面每张都这样说：

   > 保持和前面完全相同的画风、描边、上色方式和角色比例，背景透明，画：（粘贴下一只的描述）

4. **一次只画一只**，不要一张图里画好几只。
5. 如果出来的背景不是透明的，补一句「把背景改成透明 PNG」；实在去不掉也没关系，纯白或纯色背景我这边能自动抠掉。
6. 下载图片，**文件名改成清单里的中文名**，例如 `九尾狐.png`、`南山背景.png`。

## 二、统一风格（每次都要带上，至少第一次要完整发）

```
请帮我画手机游戏的角色立绘，要求：
- 风格：Q 版可爱手游风，2～2.5 头身，圆滚滚的身体，大眼睛带高光，脸颊淡淡腮红，表情灵动讨喜；
- 上色：明亮柔和的配色，赛璐璐上色加柔和渐变光影，有立体感和质感；统一的深棕色细描边；
- 题材：角色是《山海经》里的异兽，可爱化但保留原文描述的特征，"可爱里带一点点凶萌"；
- 构图：全身像，居中，3/4 微侧视角，四周留一点空白，不要裁到身体；
- 背景：透明背景 PNG；不要文字、不要边框、不要地面阴影；
- 原创造型，不要模仿任何现有游戏、动画或品牌的角色。
```

## 六、上传到 GitHub

1. 打开仓库页面 `attention-ai-yee/douyingame`，左上角分支选 **main**。
2. 进入 `art` → `inbox` 文件夹。
3. 点右上角 **Add file → Upload files**，把图片拖进去（可以一次传多张）。
4. 页面最下面点 **Commit changes**。
5. 告诉我"传好了"。我会处理好放进 `client/assets/resources/skin/`，原图挪到 `art/originals/` 保存。

## 七、尺寸说明（给我自己看的，你不用管）

导入脚本 `tools/art/import.py` 会：去掉纯色背景 → 裁掉四周空白 → 异兽缩到 384×384 PNG（压缩后约 50～100KB）→ 背景裁成 750×580 JPG（约 100KB）。
抖音小游戏首包有大小限制，图都压过；之后章节的图可以放分包。
